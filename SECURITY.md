# Security Policy

## Supported Versions

Only the latest version of ScrollToPrompt is supported for security updates.

## Reporting a Vulnerability

If you discover a security vulnerability within ScrollToPrompt, please send an email to the maintainers (placeholder@example.com). All security vulnerabilities will be promptly addressed.

Please include the following information in your report:
- Type of issue (e.g., cross-site scripting, buffer overflow)
- Location of the issue
- Potential impact
- Steps to reproduce

We appreciate your help in keeping ScrollToPrompt secure!
