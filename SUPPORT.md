# Support

If you need help with ScrollToPrompt, please follow the guidelines below.

## Documentation
Before seeking support, please check the following:
- [README.md](README.md)
- [Architecture Guide](docs/architecture.md)

## Common Issues
### Markers not appearing
- Ensure the extension is enabled in `chrome://extensions`.
- Refresh the AI chat page.
- Check if the platform's UI has changed (open an issue if so).

## Seeking Help
- **GitHub Discussions**: Best for general questions and architectural discussions.
- **GitHub Issues**: Best for bug reports and feature requests.

Please provide as much context as possible when asking for help!
