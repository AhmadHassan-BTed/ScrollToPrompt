# Roadmap

This roadmap outlines the future direction of ScrollToPrompt.

## Q2 2026: Foundation & Stability
- [x] Initial release with ChatGPT, Claude, and Gemini support.
- [x] Robust adapter-based architecture.
- [ ] Comprehensive unit and integration testing.
- [ ] Improved DOM detection for edge cases.

## Q3 2026: Feature Expansion
- [ ] **Platform Expansion**: Poe, Perplexity, HuggingChat.
- [ ] **UI Customization**: Marker colors, track visibility, position (left/right).
- [ ] **Prompt Search**: Integration with a mini-search bar to highlight specific prompts.

## Q4 2026: Advanced Integration
- [ ] **Context Sync**: Synchronize prompt history across devices using `chrome.storage.sync`.
- [ ] **Developer API**: Allow other extensions to hook into the ScrollToPrompt engine.
- [ ] **Performance Benchmarking**: Ensure zero impact on large chat histories (1000+ messages).
